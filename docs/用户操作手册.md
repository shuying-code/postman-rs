# postman-rs（pmrs）用户操作手册

> 适用版本：v0.1.0 及以上（GUI 程序 `pmrs-gui` 与命令行 `pmrs`）。
> 本手册面向最终用户，介绍安装、界面、请求构建、集合与环境、导入导出、运行器、代码生成、协议工具与常见问题。
> 快速总览见仓库根目录 [README](../README.md)；版本变更见 [CHANGELOG](../CHANGELOG.md)。

---

## 1. 简介

postman-rs 是一个用 **Rust** 编写的**本地化、无账号、无付费、无会员限制**的 Postman 风格 API 客户端。
它复刻了 Postman 最常用的**本地**能力，兼容 **Postman Collection v2.1** 格式，跨平台**单文件免安装**运行。

它提供两种使用形态：

| 形态 | 程序 | 适用场景 |
|---|---|---|
| 图形界面 | `pmrs-gui-windows-x64.exe` | 日常调试接口、可视化编辑 |
| 命令行 | `pmrs.exe` | 脚本化、CI、批量运行 |

> 本工具不连接 Postman 云端，无登录、订阅、试用、遥测，**所有本地功能对所有用户无条件可用**。

## 2. 安装与启动

### 2.1 Windows（免安装）

1. 下载 `pmrs-gui-windows-x64.exe`（GUI）和/或 `pmrs-windows-x64.exe`（CLI）。
2. **直接双击** `pmrs-gui-windows-x64.exe` 即可运行，**无需安装**（绿色单文件）。
3. 若被 SmartScreen 拦截：点击「更多信息 → 仍要运行」。

> 本项目不是 MSI/EXE 安装包，没有安装向导；提示「找不到安装程序」通常是把它误当成安装包了。

### 2.2 macOS

使用 `pmrs-gui-macos-universal`（arm64 + x86_64 通用）。首次运行若被 Gatekeeper 拦截：

```bash
xattr -d com.apple.quarantine ./pmrs-gui-macos-universal
# 或：右键 → 打开
```

### 2.3 Linux

下载 `pmrs-gui-linux-x64`，赋可执行权限后运行：

```bash
chmod +x pmrs-gui-linux-x64
./pmrs-gui-linux-x64
```

### 2.4 容器（仅 CLI）

```bash
docker run --rm ghcr.io/shuying-code/postman-rs:latest send "https://httpbin.org/get" -m GET
```

## 3. 界面总览

GUI 采用「左侧导航 + 右侧工作区」布局：

- **顶栏**：品牌色渐变条、全局搜索框、环境选择、主题选择、「刷新」等。
- **左侧导航（分段式）**：`集合` / `环境` / `全局` / `历史` / `工具` / `控制台`。
- **右侧主区**：多标签的请求构建器与响应面板。

左侧各页功能：

| 页 | 作用 |
|---|---|
| 集合 | 集合 / 文件夹 / 请求树，点击请求载入到标签 |
| 环境 | 增删改环境变量，切换当前环境 |
| 全局 | 维护全局变量 |
| 历史 | 查看历史请求记录 |
| 工具 | 导入、集合运行器、代码生成、Cookie 管理、WebSocket 工作台等 |
| 控制台 | 分段记录每次请求/响应与脚本测试日志（可清空 / 复制全部） |

## 4. 快速上手：发送第一个请求

1. 顶栏点「＋ 新建标签」（或按 `Ctrl+N`）新建一个请求标签；首次使用左栏为空属正常。
2. 在方法下拉选 `GET`，URL 填 `https://httpbin.org/get`。
3. 点右侧「发送」（或按 `Ctrl+Enter`）。
4. 下方「响应体 / 响应头 / Cookies / 测试 / 计时」查看结果。

> 想把示例数据导入体验：`pmrs import examples/demo_collection.json --format postman`，再刷新左栏集合。

## 5. 请求构建器详解

每个标签包含以下子标签页：

- **参数（Params）**：查询参数键值表，自动同步到 URL 的 query 部分。
- **授权（Auth）**：类型可选 `无 / Bearer 令牌 / 基本认证 / API 密钥`（Header 或 Query 方式）。
- **请求头（Headers）**：逐行键/值编辑，键列约 30%、值列占其余，行高对齐 Postman。
- **请求体（Body）**：类型可选 `无 / form-data / x-www-form-urlencoded / raw / binary / GraphQL`。
  - `raw` 支持 `Text / JSON / XML / HTML / JavaScript` 子语言与一键格式化；
  - 表单类支持逐行启用、键、值、类型（文本或文件）；
  - `GraphQL` 提供独立 Query 与 Variables 编辑框。
- **测试（Tests）**：声明式断言（见第 10 节）。
- **脚本（Scripts）**：pre-request / test 脚本（轻量 `pm.*`）。
- **设置（Settings）**：请求级设置（如超时等）。
- **描述（Desc）**：Markdown 描述，保存时写入 `item.description`，导出 v2.1 一并保留。

发送在后台线程执行，界面不卡顿；支持 `{{变量}}` 与当前环境下拉解析。

## 6. 标签管理

- **新建**：点「＋ 新建标签」或按 `Ctrl+N`，在弹窗中命名并选择方法。
- **重命名**：**点击当前标签标题**或**双击任意标签名**进入内联编辑；`Enter` 保存、`Esc` 取消、清空则不保存。
- **关闭**：点标签右侧 `×` 或按 `Ctrl+W`（会二次确认）。
- **切换**：点击标签标题。

---

## 7. 变量与环境

- 语法：`{{name}}`，发送前递归解析。
- 作用域优先级（高 → 低）：`命令行变量 > 迭代数据 > 环境 > 集合 > 全局`。
- 动态变量示例：`{{$randomInt}}`、`{{$randomUUID}}`、`{{$guid}}`、`{{$timestamp}}`、`{{$isoTimestamp}}`、`{{$randomEmail}}`、`{{$randomCity}}` 等（含 `$randomLorem*` / `$randomImageUrl` / `$randomAvatar` 等约 30+ 个）。
- 环境：左侧「环境」页可增删改变量并保存；顶栏环境下拉切换当前环境。

---

## 8. 集合与文件夹

- 集合 / 文件夹 / 请求构成树结构；支持集合变量。
- **保存当前请求到集合**：点「保存」，集合名留空=当前集合，请求名留空=标签标题。
- **继承语义**：发送时自动继承集合/文件夹级鉴权、变量与 pre-request/test 脚本；全局变量在 GUI 发送时生效。
- 支持文件夹级 pre-request/test 脚本与文件夹变量。

---

## 9. 导入与导出

### 导入（左栏「工具 → 导入」）

支持格式：`Postman v2.1 / v2.0 / v1`、`OpenAPI 3 / Swagger 2（JSON）`、`cURL`、`HAR`。
同名集合会自动合并。命令行等价：

```bash
pmrs import examples/openapi.json --format openapi
pmrs import "curl 'https://api.test/x' -X POST -d '{\"a\":1}'" --format curl
pmrs import har.json --format har
pmrs import postman.json --format postman
```

### 导出

- 集合导出为 **Postman Collection v2.1** JSON，路径留空=`~/.postman-rs/exports/`。
- URL 栏的 **cURL** 按钮下拉可：`复制当前请求为 cURL`、`导出为 cURL 脚本文件…`、`从 cURL 导入（粘贴）…`。

---

## 10. 断言（Tests）

支持声明式断言：`status` / `json_path` / `json_path_exists` / `body_contains` / `body_equals` / `header` / `max_time_ms` / `response_time` / `regex`；
并解析常见 `pm.test(...status(200))`、`to.have.header(...)` 形态。响应面板「测试」页展示每条断言结果。

---

## 11. 集合运行器（Collection Runner）

左栏「工具 → 集合运行器」，或命令行：

```bash
pmrs run examples/demo_collection.json -e examples/demo_environment.json -i 3
pmrs run collection.json -d data.csv --delay 200 --bail
```

能力：多迭代、CSV/JSON 数据驱动、延迟、断言统计、「失败即停」（`--bail`）、CI 退出码、报告（`--report`）。

---

## 12. 代码生成

左栏「工具 → 代码生成」，或命令行：

```bash
pmrs codegen --collection examples/demo_collection.json --item "Get Hello" --lang rust
pmrs codegen --url https://api.test/x --method POST --lang curl
```

支持语言：`curl / http / rust(reqwest) / python(requests) / js(fetch) / go(net/http) / nodejs(axios) / java(okhttp) / csharp / php / ruby / powershell / swift`。

---

## 13. 响应面板

- **响应体**：JSON 语法高亮 + 自动美化（可切换「美化」）+ 复制。
- **响应头**：查看返回头。
- **Cookies**：查看本次响应写入的 Cookie。
- **测试**：断言结果。
- **计时**：状态码、耗时、响应大小等。

## 15. 主题与外观

顶栏「主题」下拉可选 8 套配色：`0 Postman 浅色 / 1 Postman 深色 / 2 午夜蓝 / 3 石墨灰 / 4 暖沙 / 5 森林绿 / 6 樱粉 / 7 高对比`。
选择会自动记忆（`~/.postman-rs/gui_theme.txt`）；也可用 `PMRS_THEME=0..7` 指定。

## 16. 网络与证书

通过环境变量配置代理、证书等（详见 README「环境变量」）：

| 变量 | 作用 |
|---|---|
| `PMRS_PROXY` | HTTP/SOCKS 代理，如 `http://127.0.0.1:7890` |
| `PMRS_CA_BUNDLE` | 自定义 CA 证书（PEM） |
| `PMRS_CLIENT_CERT` / `PMRS_CLIENT_KEY` | 客户端证书 / 私钥（mTLS） |
| `PMRS_INSECURE=1` | 跳过 TLS 校验 |
| `PMRS_CONNECT_TIMEOUT` | 连接超时（秒） |
| `PMRS_MAX_REDIRECTS` | 最大重定向次数（默认 10） |

持久 Cookie 保存在 `~/.postman-rs/cookies.json`。

## 17. 工作区与文件位置

默认工作区 `~/.postman-rs`（可用 `PMRS_HOME` 覆盖）：

```
~/.postman-rs/
├─ collections/*.json
├─ environments/*.json
├─ exports/            # 导出的集合 / cURL 脚本
├─ history.jsonl
├─ cookies.json
└─ gui_theme.txt
```

纯文件、可纳入 git、无数据库、无云端。

## 19. 常见问题（FAQ）

**Q：编译后的文件在哪？**
GUI：`dist/pmrs-gui-windows-x64.exe`；CLI：`dist/pmrs-windows-x64.exe`。

**Q：Windows 提示「无法安装」？**
本项目是绿色单文件，**免安装**，直接双击 exe 运行即可。

**Q：怎么换主题？**
顶栏「主题」下拉，或用 `PMRS_THEME=0..7`。

**Q：Mac 版怎么获得？**
macOS 二进制需在 Mac 真机上用 `scripts/build-macos.sh` 构建，或使用仓库 CI。

**Q：需要账号或付费吗？**
不需要。无登录、无订阅、无会员限制，所有本地功能无条件可用。
