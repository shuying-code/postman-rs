# 补充一：Postman 功能矩阵与协议实现细节

> 面向「复刻」的细化拆解。所有结论来自 app.asar 静态文件与 bundle 文本，标注为观察（静态）/推断。

---

## 1. 请求构建器（Requester）细粒度能力

### 1.1 HTTP 方法
`GET / POST / PUT / PATCH / DELETE / HEAD / OPTIONS / COPY / LINK / UNLINK / PURGE / LOCK / UNLOCK / PROPFIND / VIEW`（Postman 支持自定义方法字符串）。

### 1.2 URL 结构（Postman URL 对象）
```
{
  "raw": "https://api.test/{{path}}?a=1&b=2",
  "protocol": "https",
  "host": ["api","test"],
  "path": ["{{path}}"],
  "query": [{"key":"a","value":"1","disabled":false}],
  "variable": [{"key":"path","value":"users"}],
  "hash": ""
}
```
- 支持 `{{variable}}` 路径/查询/主机内联变量。
- Query 参数可视化编辑，可批量 URL 编码。

### 1.3 Headers
- 键值表，支持禁用（不发送）、自动头（`Content-Type`、`Content-Length`、`Host`、`User-Agent`、`Accept`）、隐藏自动头。
- Header 预设（Presets）：JSON / XML / Form / Text / HTML / JavaScript。

### 1.4 Body 类型（`body.mode`）
| mode | 说明 | 关键字段 |
|---|---|---|
| `raw` | 原始文本 | `raw` + `options.raw.language`（json/xml/html/text/javascript） |
| `urlencoded` | 表单 | `urlencoded:[{key,value,type,disabled}]` |
| `formdata` | 多部分 | `formdata:[{key,value,type:file/text,src}]` |
| `file` | 二进制文件 | `file.src` |
| `graphql` | GraphQL | `graphql.query` + `graphql.variables` |

### 1.5 鉴权（`request.auth.type`）
`noauth / basic / bearer / apikey / oauth1 / oauth2 / digest / ntlm / awsv4 / hawk / jwt / edgegrid / asap / inherit`。变量可注入；OAuth2 支持授权码/PKCE/客户端凭证/密码模式（回调 `http://127.0.0.1`）。

### 1.6 请求设置（`request` / 全局）
- 重定向：跟随/不跟随、最大次数、是否保留方法。
- 超时（连接/读取/整体）。
- 代理：系统代理/自定义 HTTP/HTTPS/SOCKS、代理认证。
- 证书：客户端证书（PFX/PEM）、CA、SSL 校验开关、SNI。
- Cookie：Cookie 罐（`pm.cookies`）与域管理。
- 编码/压缩：gzip/deflate/br 自动解压。

## 2. 集合与工作区管理

- **集合树**：Collection → Folder（可多层）→ Request。拖拽排序、复制、移动。
- **集合级配置**：集合变量、集合级 Auth、集合级 pre-request/test 脚本、集合级描述（Markdown）。
- **示例（Examples）**：保存请求的多份响应示例；Mock 与文档使用。
- **工作区（Workspace）**：个人 / 团队 / 公开。团队与公开工作区需登录并同步云端。
- **本地文件工作区**：新版支持「本地文件系统工作区」，以文件夹形式保存集合与环境，配合 `main-file-system-watcher-*`、`main-git-ipc-handlers`（内置 git 能力）实现本地版本管理（推断：基于文件监听 + git 命令封装）。
- **历史（History）**：自动记录请求，按时间倒序，可保存为请求/集合。

## 3. 变量与动态变量

### 3.1 变量作用域与优先级
`local/temp (pm.variables)` > `data (pm.iterationData)` > `environment` > `collection` > `globals`。解析用 `{{name}}`；嵌套变量递归解析。

### 3.2 动态变量（bundle 命中确认）
`{{$randomInt}}`、`{{$randomUUID}}`、`{{$guid}}`、`{{$timestamp}}`、`{{$isoTimestamp}}`、`{{$randomAlphaNumeric}}`、`{{$randomBoolean}}`、`{{$randomFirstName}}`、`{{$randomLastName}}`、`{{$randomEmail}}`、`{{$randomPassword}}`、`{{$randomCity}}`、`{{$randomCountry}}`、`{{$randomPhoneNumber}}`、`{{$randomIP}}`、`{{$randomColor}}`、`{{$randomHexColor}}`、`{{$randomAbbreviation}}` 等。

### 3.3 变量类型
`string / secret / number / boolean / any / null`；Secret 值在 UI 中隐藏，Vault 集成用于团队密钥。

## 4. 脚本沙箱（pm.*）

### 4.1 生命周期
- `pre-request`：请求发送前执行，可改 URL/Header/Body、设置变量、发辅助请求。
- `test`：响应返回后执行，可断言、提取变量、写环境。

### 4.2 常用对象
`pm.info`（事件名/迭代/请求名）、`pm.request`、`pm.response`、`pm.environment`、`pm.globals`、`pm.collectionVariables`、`pm.variables`、`pm.iterationData`、`pm.cookies`、`pm.sendRequest`、`pm.test`、`pm.expect`、`pm.visualizer`、`pm.execution`、`pm.vault`。

### 4.3 断言范式（chai）
```js
pm.test("状态码 200", () => pm.response.to.have.status(200));
pm.test("含字段", () => {
  const j = pm.response.json();
  pm.expect(j.items).to.be.an("array");
});
```

### 4.4 执行隔离
脚本在独立 worker 线程（`execution-worker.js`）+ Hermes 引擎中运行，提供超时与内存限制；`pm.sendRequest` 走 runtime，不阻塞主线程。

## 5. Collection Runner

| 能力 | 说明 |
|---|---|
| 选择集合/文件夹 | 运行范围 |
| 迭代次数 | 1..N 或由数据文件行数决定 |
| 数据文件 | CSV / JSON（DuckDB 引擎解析） |
| 延迟 | 请求间固定延迟 |
| 保存响应 | 可选是否持久化响应体 |
| 断言统计 | 通过/失败计数、逐请求结果 |
| 中止条件 | 失败即停、错误阈值 |
| 报告 | 本地结果；云端/CLI 可上报 |

## 8. 性能测试

- `perftest.js` / `perftestExecute.js` / `perftest-*.min.js` + DuckDB 数据集引擎。

## 12. 功能优先级（复刻时）

| 优先级 | 功能块 | 理由 |
|---|---|---|
| P0 | HTTP 发送、集合/环境/变量、历史、导出 v2.1、cURL 导入、代码生成(cURL/Rust/Python/JS) | 日常 80% 使用 |
| P1 | Runner（迭代+数据文件+断言）、更多导入(OpenAPI/HAR)、更多代码生成语言 | 自动化 |
| P2 | WebSocket、本地 Mock、Cookie/鉴权矩阵（Digest/NTLM/AWSv4） | 进阶协议 |
| P3 | gRPC/MQTT/GraphQL、性能测试、本地文件工作区+git | 专业场景 |
| — | 云端协同/团队/Monitor/Vault/Governance | 明确不实现（需登录付费），本地替代 |
