## 2. 关键改动摘要

- `src/variables.rs`：`VarContext::merged()` —— 把多作用域合成单表（高优先级覆盖），供脚本 `pm.*.get` 使用。
- `src/scripting.rs`：新增 `ScriptEnv{vars,iter,method,url}` 与 `run_env()`；`run()` 保持向后兼容（空 env 委托）；`eval()` 增加各 `get` 与 `pm.request.*` 解析；新增单测 `get_variables_iteration_and_headers`。
- `src/http.rs`：`cookies_dump/cookie_set/cookie_delete/cookie_clear` 直接操作持久 Cookie jar 并落盘。
- `src/runner.rs`：pre-request 与 test 脚本改用 `run_env`，注入 `ctx.merged()`。
- `src/bin/gui.rs`：侧栏分段变为 `集合/环境/全局/历史/工具`（新增"全局"页）；工具页新增 Cookie 管理器；响应区新增保存到文件；顶部 `update()` 增加键盘快捷键；发送线程前置/测试脚本改用 `run_env`；新增字段 `resp_save_path / globals_edit / globals_loaded / cookie_new_host / cookie_new_kv`；新增 `PMRS_GUI_SIDEBAR`（0集合 1环境 2全局 3历史 4工具）初始侧栏环境变量，便于测试/演示，默认 0 不影响正常使用。
