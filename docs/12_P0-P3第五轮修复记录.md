## 1. 本轮复核结论（第五轮）

第四轮列出的 P0 中，第 2 批（`11_`）已修好：响应保存到文件、GUI 全局变量编辑器、Cookie 管理器、
快捷键、`pm.*` 读取子集。**本轮重读源码后确认仍存在以下 P0–P3 问题并已修复：**

| # | 级别 | 问题 | 现状（复核证据） | 本轮处置 |
|---|---|---|---|---|
| 1 | **P0** | `pm.expect(...)` 断言匹配器覆盖过窄 | 仅 eql/equal/above/below/least/most/include/true/false/ok，缺 `.not`、`lengthOf`、`property`、`a/an`、`match`、`oneOf`、`closeTo`、数组 include、empty/null/exist —— 常见脚本**静默失败** | 扩展匹配器引擎 + 单元测试 |
| 2 | **P1** | **GUI 发送时全局变量不生效** | `gui.rs::ctx_from` 只并入 环境 + 集合变量，**未并入 globals**；全局变量编辑器保存后发送时被忽略 | `ctx_from` 末尾并入 globals（最低优先级） |
| 3 | **P1** | GUI 发送不继承集合/文件夹级 auth / 变量 / 脚本 | 仅 runner 有继承；GUI 发送线程只用标签自身 auth 与脚本 | 新增 `collect_inherited`，发送时套用集合/文件夹 auth（标签未设时）、文件夹变量、集合/文件夹 pre-request/test 脚本 |

| 6 | **P3** | GUI 方法下拉仅 7 种 | 引擎支持任意方法，下拉仅 GET/POST/PUT/PATCH/DELETE/HEAD/OPTIONS | 下拉扩展到 16 种（加 COPY/LINK/UNLINK/PURGE/LOCK/UNLOCK/PROPFIND/VIEW/TRACE） |

> 说明：`#2` 属于「名不副实」缺陷——GUI 有全局变量编辑器，但发送时并不使用，属数据/预期不一致，优先级 P1。

## 2. 各修复细节与证据

### 2.1 P0 — `pm.*` 断言匹配器扩展（`src/scripting.rs`）
- 重写 `pm.expect(EXPR).to.<chain>(ARGS)` 解析：支持链式修饰 `to.` / `be.` / `have.` 与 **`.not` 取反**。
- 新增匹配器：`lengthOf` / `length`、`property`（可带期望值）、`a` / `an`（类型）、`match(/regex/)`、
  `oneOf([...])`、`closeTo(expected, delta)`、`include`（数组按成员、字符串按子串）、`empty`、`null`、`exist`、
  `atLeast/atMost/approximately` 等别名。
- `pm.response.json()` 取值时保留真正的 `null`（此前被折叠为空串），使 `.to.be.null` / `.to.exist` 语义正确。
- 新增单测 `chai_matchers_not_property_length_match`（9 例含负例）。

### 2.2 P1 — GUI 全局变量生效（`src/bin/gui.rs`）
- `ctx_from(coll, env)` 末尾追加 globals 作用域（仅启用项），优先级最低，符合 `env > collection > globals`。

### 2.3 P1 — 集合/文件夹继承（`src/bin/gui.rs`）
- 新增 `collect_inherited(coll, item_path)` → `(auth, folder_vars, events)`：沿路径取最深 auth、合并文件夹变量、
  收集集合+文件夹事件。
- 发送线程中：标签未设鉴权（`none`/`inherit`）时套用继承 auth；文件夹变量插入「环境之下、集合之上」；
  继承的 pre-request 脚本前置、test 脚本后置。
- 避免重复：标签自带 Bearer/Basic/ApiKey（已生成 Authorization 头）时不套用继承 auth。

### 2.4 P1 — 控制台（`src/bin/gui.rs`）
- `GuiApp.console: Vec<String>`；侧栏新增「控制台」分段（支持清空/复制全部/计数）。
- 发送时记录 `→ METHOD URL`；响应到达记录 `METHOD URL → CODE STATUS (ms)` 与脚本测试通过/失败逐条。
- 环境变量 `PMRS_GUI_SIDEBAR=5` 可直接打开控制台（测试/演示用）。

### 2.5 P0/P1 — 请求描述（`src/bin/gui.rs`）
- `Tab.description`；请求子标签新增「描述」页（多行 Markdown 文本，可从响应体填入）。
- `flatten` 改为携带描述，选中请求时回填 `Tab.description`；`save_active` 写入 `Item.description`。
- 导出 v2.1 时 `item.description` 随原有序列化一并保留。

### 2.6/2.7 P3 — 方法下拉与动态变量
- 方法下拉扩充至 16 种（`method_color` 未命中项回退次要色，不影响渲染）。
- `variables.rs` 补 `$randomLoremWord(s)/Sentence(s)/Paragraph(s)/Text/Slug`、`$randomImageUrl`、
  `$randomAvatar`、`$randomUserName`、`$randomBankAccountName/Iban/Number/Bic/Country`、`$randomIban`、
  `$randomBic`、`$randomCreditCardNumber`、`$randomAmount` 等；新增单测 `lorem_and_image_dynamic_vars`。
