> 对象：`F:\codex工作区\postman-rs`

## 0. 一句话结论
本地 HTTP 核心（发送 / 集合 / 环境 / 变量 / 历史 / Runner / 导入导出 / 代码生成 / 断言）已具备；但对照 Postman 仍有大量「未复刻」，分三类：
- A 类：文档声称但代码未实现/不符（属于「名不副实」，优先修正文档或补实现）。
- B 类：纯本地能力确实缺失（可补）。
- C 类：需云端/登录/付费（本项目按设计不做）。

## 2. 第二遍：按 Postman 功能面状态
图例：✅已实现 / 🟡部分 / ❌缺失（本地可补）/ 🚫按设计不做（云端·登录·付费）
### 2.1 请求构建器
- 方法：🟡 引擎支持任意方法字符串；GUI 下拉仅 7 种，无 COPY/LINK/UNLINK/PURGE/LOCK 等专有方法入口
- URL 结构化对象（protocol/host/path/query/variable/hash）：❌ 仅保留 `raw`，导入后 query 的 disabled 标志、path 变量丢失
- Query 可视化：🟡 CLI/gui 参数页（本轮新增），但 disabled 不保留
- Path 变量 `:id`：❌ 仅支持 `{{}}`，不支持 Postman 的 `:path` 结构与 url.variable
- Headers：✅键值+禁用；❌ 自动头管理、预设(Preset)、隐藏自动头
- Body：🟡 引擎+CLI 支持 raw/urlencoded/formdata/file/graphql 五种；GUI 仅 json/text/none
- 请求设置：❌ 重定向开关、连接/读取超时分离、代理、证书、SSL 校验、SNI、gzip/br 解压（reqwest 未开 compression feature）
### 2.2 鉴权
- none/basic/bearer/apikey(header/query)：✅
- oauth1、oauth2(授权码/PKCE/客户端凭证/密码/刷新)、digest、ntlm、awsv4(SigV4)、hawk、jwt、edgegrid、asap、inherit：❌（且静默忽略不报错）
### 2.3 变量
- 环境/集合/CLI 变量优先级、递归解析：✅
- Globals（全局变量）作用域/文件/命令：❌
- local/temp(pm.variables)、iterationData 脚本侧：🟡 仅 Runner 数据行可用，无脚本
- 变量类型 secret/number/boolean：🟡 全按字符串处理；无 secret 掩码、无系统密钥链
- 动态变量：🟡 约 19 种；Postman 还有大量（公司/职位/经纬度/图片URL/金额/商品/文件路径/lorem/UA/域名/locale/IPv6/MAC/日期 等）缺失
### 2.4 脚本与测试（pm.*）
- pre-request 脚本执行（改请求、pm.sendRequest）：❌
- test 脚本完整 JS（Hermes/boa/rquickjs）：❌
- 断言：✅status/json_path/body_contains/header/max_time_ms；❌ schema/regex/耗时组合/自定义 chai/visualizer
- 集合级、文件夹级 event 执行：❌（Collection.event 解析但不执行；Runner 只用 req.event+item.event）
### 2.5 Collection Runner
- 迭代 / CSV·JSON 数据 / 延迟 / 断言统计 / CI 退出码：✅
- 按文件夹运行、失败即停、保存响应、报告导出、DuckDB 数据：❌
- 继承集合级鉴权：❌（runner 未合并 collection.auth）
### 2.6 导入/导出
- 导入 postman(v2.1)/openapi(JSON)/curl/har：🟡（各有缺失，见 2.1 与第一遍）
- 导入 环境：✅；导入 globals：❌；导入 v1/v2.0：❌/不可靠
- 导出集合 v2.1：✅；导出环境/globals、v2.0/v1、OpenAPI：❌
- 导入同名集合合并：❌（同名直接覆盖，有数据丢失风险）
- 保留 examples（保存的响应示例）：❌（`Item` 无 `response` 字段，导入即丢）
### 2.7 代码生成
- curl/rust/python/js/go/nodejs：✅；Postman 30+ 语言：❌
- 表单/文件/graphql 体、除 curl 外的鉴权：🟡/❌
### 2.8 集合/工作区管理
- 集合/文件夹/请求 树结构：✅（数据结构层面）
- 增删改、移动、复制、拖拽排序、重命名：❌（CLI 仅 new/list/show；GUI 只读+载入）

### 2.10 网络与连接

## 3. 优先级建议（若要继续补）
- P0（正确性/数据完整性，先修）：1) 未支持鉴权静默忽略 → 显式报错或提示；2) 同名导入覆盖 → 合并或改名保留；3) `Item` 补 `response` 字段防 examples 丢失；4) reqwest 开 gzip/brotli/deflate/cookies + 二进制响应处理；5) globals 作用域/文件/命令。
- P1（高频本地）：集合树编辑（增删改名/文件夹）、GUI 导入/Runner/代码生成入口、环境变量编辑、env/globals 导出、OAuth2 取 token、代理/证书/超时分离。
- P2：Cookie 罐、断言语义扩展、Runner 文件夹/失败即停/报告、codegen 语言扩充、动态变量补全、GUI 响应 Cookies/Timing/TestResults。
- P3：多协议工作台(WS/MQTT/gRPC/GraphQL/SSE)、Mock、性能测试、主题/语法高亮。
- 🚫 按设计不做：登录/团队/云端同步/Monitor/Vault/Governance/Postbot。
