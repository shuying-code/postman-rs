## 各批细节

### 第 1 批（P0-1 结构化 URL）
- `model.rs`：`UrlSpec` 扩展并自定义 serde；`effective_url()` 做 `:name` 路径变量替换、按 enabled 重建 query、追加 hash。
- `http.rs::execute_cfg`、`codegen.rs`、`main.rs`、`runner.rs` 统一改用 `effective_url()`。
- GUI `Tab.params` 改 `Vec<KVRow>`，新增 `path_rows`/`hash`，重写 `parse_query`/`detect_path_vars`/`rebuild_url`。

### 第 2 批（P0-2 导入）

### 第 3 批（P0-3 codegen body）

### 第 4 批（P1-1 集合树 CRUD）

### 第 5 批（P1-2 OAuth2 + P1-4 示例）
- `Tab.oauth2`、`auth_extra`；`build_auth` 覆盖 oauth2/oauth1/awsv4/jwt/digest/ntlm；响应“保存为示例”与示例回放。

### 第 7 批（P2-1 计时 + P2-3 SOCKS）
- `ResponseRecord` 增 `dns_ms/tcp_ms/ttfb_ms/download_ms`；GUI 计时标签分阶段展示。

### 第 9 批（P3-1 pm.* 脚本引擎）

## 追加修复：左侧栏"移动鼠标一直变宽"

现象：移动鼠标时左侧面板持续变宽（约每帧 +1~2px）。

根因：`egui::SidePanel::left(...).resizable(true)` 每帧会把内容的最小宽度记忆为面板新宽度；侧栏内多处"占满可用宽度"的控件（`ComboBox::width(ui.available_width())`、`desired_width(INFINITY)` 等）存在 1~2px 的舍入溢出，于是被逐帧累加成新的面板宽度，形成反馈循环。

修复：
- 侧栏改为固定宽度绘制（`resizable(false).exact_width(w)`），宽度由 `GuiApp.side_w` 维护，从而内容溢出无法再改变面板宽度。
- 在面板右缘自绘拖拽手柄（`Sense::drag` + `ResizeHorizontal` 光标），保留手动调整能力（范围 240–520pt）。
- 顺带修正 `install_style` 未设置 `visuals.dark_mode` 的问题（深色主题基础视觉正确）。

验证：用 `PrintWindow` 连续 6 次采样侧栏/主区分界线像素位置，修复前 469→475 持续增长，修复后稳定为同一值。

## cURL 等功能补充

- 增强 cURL 导入解析器（`import_export::import_curl`）：
  - 支持 `-F/--form`（multipart，含 `name=@file` 文件字段）、`-b/--cookie`（合并为 Cookie 头）、`-A/--user-agent`、`-e/--referer`；
  - 支持 `-G/--get`（把 `-d` 数据拼入查询串）、`--data-urlencode`（生成 x-www-form-urlencoded 体）、多个 `-d` 合并；
  - 支持 `-T/--upload-file`（binary 体）、`--json`（raw JSON + Content-Type）、`--url`、`--flag=value` 内联写法；
  - 忽略无对应模型的开关（`-k/--insecure`、`-x/--proxy` 等，安全地消费其参数）。
  - 请求体类型智能判定：formdata / urlencoded / file / raw(json|text)。
- 新增单元测试 3 个（form+cookie+UA、GET+urlencode+多 -d、upload+json），`import_export` 共 9 项通过。
- GUI 补充：
  - 「工具」面板新增「从 cURL 导入（粘贴）」多行框 + 「解析为新标签」按钮（把 curl 命令解析成新请求标签）；
  - 请求 URL 行右侧新增「cURL」快捷按钮，一键复制当前请求为 curl 命令；
  - 「代码生成」区块本就支持 curl 等 13 种语言，可直接复制。
